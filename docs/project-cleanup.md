# 项目清理与验证入口

本次以 `src/main.tsx` 的静态导入、动态 import 和类型依赖为边界核对当前产品实现。
工作开始前已经存在的 v2 后端、工作区与原生计算改动随对应功能提交，未回退既有实现。

## 删除范围

- 退役的 18 个旧页面／组件，以及 24 个仅服务旧前端的状态、Agent、服务和辅助模块。
- 11 个仅覆盖退役链路的 TypeScript 测试；混合测试中保留共享 STL 往返与损坏输入检查。
- 15 个旧 UI、演示或重复 HTTP 脚本；当前界面的验收合并到 `scripts/core-ui-test.mjs`。
- 14 张无引用的旧页面资源图，以及本机生成的截图、日志、安装临时目录、下载件和 dist。
- 不再使用的 Zustand 依赖与对应锁文件记录。

不按文件名或测试数量删除当前功能回归。v2 任务、记忆、建模恢复、工程管理、
模块化脚本、数值校核、原生几何与后端兼容契约测试继续保留。

## 保留边界

`server/` 仍被持久后端及原生回归复用，不能当作旧页面代码整体删除。
`src/core/` 的材料、类型、STL 和场投影仍用于工作区与显式旧工程导入。
共享全局 CSS 保持不变，避免破坏控件与层叠规则。
`.vision-workspace` 的工程数据库／模型制品、本地 Python、依赖与记忆模型保留；
历史 JSON 和 NPZ 数值证据保留。历史说明中的截图路径可能指向已清除的本机产物。

## 验证命令

```powershell
npm test
npm run build
npm run test:python
npm run test:measurements
npm run test:native
npm run test:backend
npm run test:core-ui
```

`test:python` 使用 Python 3.13，`test:measurements` 使用装有 USD BRep 的 Python 3.12。
原生测量文件改名为 `tests/native_cad_inspection.py`，防止被错误解释器自动发现。
设置 `VISION_TEST_NATIVE_CORE=1` 可开启完整原生生命周期、任务与求解器校核；
设置 `VISION_MEMORY_SEMANTIC=0` 可让普通离线回归不加载本地语义模型，
显式向量库融合／重排测试仍独立验证相关流程。

浏览器脚本使用独立临时工程，覆盖新建工程、草稿恢复、真实 CAD／FEA、
证据显示、刷新恢复和三个宽度的布局；结束后清理临时工作区，不调用远程模型。
清理前前端 59 项测试与生产构建通过；清理后的前端 11 项测试覆盖保留实现，
测试数量下降来自删除旧链路，不能用数量变化声称覆盖率提升。
