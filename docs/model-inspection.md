# 模型测量与物理属性

模型左侧新增「测量与物理属性」。选择类型为体、面、边或顶点，支持原生对象列表、视口点击、Ctrl / ⌘ 多选。拖动仍为旋转视图；关闭拾取后保留属性读数。点击「整个模型」恢复全体统计。

## 数据与交互设计

每次查询绑定工程、原生 CAD artifact 和当前材料。视口网格交点仅作为定位线索，后端对真实裁剪面、有限边、顶点做最近点查询以确定对象。面孔洞不属于可拾取面区域。边、点的点击容差根据视口像素尺度确定，可从列表精确选择相邻或遮挡的对象。

属性根据实际选择动态生成，不依赖模型模板、特征名称或预先设置的直径、壁厚等字段。

| 对象 | 属性 |
| --- | --- |
| 模型、体、多体 | 表面积、包围尺寸、闭合实体体积、质量、真实质量中心、质心惯性矩与惯性积 |
| 面、多面 | 裁剪面积、面积形心、边界环长；单面附带平面/曲面判定、采样位置和外向法线 |
| 边、多边 | 原生边长；单边附带端点、共面判定、采样位置、局部曲率、曲率半径和切线 |
| 顶点、多顶点 | 原生顶点坐标 |
| 两个体 | 原生边界距离与空间关系 |
| 点与点/体/面/边 | 原生边界最短距离 |
| 两个平面 | 外向法线夹角 |
| 任意平面与实体 | 截面积、截面形心、法向正侧局部实体体积、质量、质心、惯性及含切面的表面积 |

面、边通过原生边界采样线高亮，顶点及采样位置通过点标记显示。这些线用于显示，属性使用内核查询和数值积分。曲线参数中点用于列表选边的局部曲率计算，视口选边使用点击位置在边上的投影。

## 视口参数标注与透明 HUD

原生模型载入后自动查询整体属性。包围尺寸通过三维双向尺寸线显示，面积、体积、局部边长/曲率、采样坐标和点间距离通过原生几何锚点与引线定位。包围尺寸始终标为「包围尺寸」，不会冒充零件的设计尺寸；曲线弧长不会被画成端点弦长尺寸线。

文字卡片保持朝向屏幕，随模型旋转、缩放和平移更新位置，避开右上角 HUD、视图工具条及其他标注。最多显示 3 组重点标注，限制引线长度，空间不足时自动收起部分标注；完整数值仍保留在测量面板。重合锚点的参数合并显示。

右上角 HUD 使用透明背景、淡青色刻度线、角标和轻微文字辉光。选中对象后默认显示「所选几何」，「整体物性」另页保留整件的质量、密度、质心和惯性数据。「测量范围」表示统计哪些对象，「对象类型」表示原生拓扑类别，两者分开显示。体按原生结构进一步区分闭合实体、曲面体、线框体及混合体。选体或查询截面时，物性范围相应变化。几何或材料改变后清空旧几何标注及物性汇总。

智能模式把选中拓扑、相邻几何证据、可测量项和简要设计上下文交给已配置的 LLM，选择与当前特征相关的参数。LLM 只规划测量与解释；数值、单位、锚点由原生内核按测量编号重新查询。模型旁最多显示 1–3 个重点参数，其余收进详情。特征名称属于智能解读，不替代原生对象类型；用途推测、缺失的公差或未支持的测量会单独说明。

「视图设置」提供独立的「显示几何参数标注」「显示属性 HUD」开关。关闭拾取不会清除参数标注，收起左侧面板也会保留当前选择与标注。

## 精度与物理含义

- 世界坐标采用 mm；面积 mm²、体积 mm³、密度 kg/m³、质量 kg、质量惯性 kg·mm²。
- 质量属性采用当前材料均匀密度。面不是实体，未指定厚度的曲面体不返回体积、质量或实体惯性。
- 质心由几何积分计算，不使用包围盒中心。多体采用平行轴定理汇总到共同质心；相互重叠的独立部件会重复计入，面板明确提示。
- 积分相对精度支持 0.0001、0.001、0.01；0.0001 是当前内核接口的积分下限，与显示网格离散公差不同。显示有效数字不等于实测或几何精度。
- 截面查询只操作副本，以包围整个部件的定向闭合盒进行布尔相交，避免内核 `cut()` 返回未封闭壳体。保留区域方向在界面明确显示。
- 面边界总长统计裁剪环中的边出现次数，包含接缝和多面共享边，不能当成所选面并集的外周长。
- 曲率半径是局部值，不将自由曲线认定为圆；曲面不虚构统一半径、壁厚、曲率或材料参数。

## 有效性与限制

几何或材料变化时清空旧选择、读数及高亮，重新查询整体属性。请求通过取消与序号检查避免旧响应覆盖新选择；失败显示错误并提供重试，不保留上一轮数值冒充本轮结果。

当前支持均匀材料。任意裁剪面之间、任意两条曲线之间的全局最短距离，曲面的局部主曲率、截面面积惯性矩以及自动壁厚识别尚未实现；对不支持的双对象组合显示说明，不用网格或包围盒近似代替。高亮线为显示采样，不是精确曲线导出。切割平面与原有边界完全重合时建议稍移平面，退化或无法封闭的局部区域会报告错误。

## 验证

- `npm run test:measurements`：真实 USD BRep 内核，覆盖偏心孔、裁剪孔洞、曲面体、圆边、顶点、多体平行轴定理和距离、斜截面及带孔截面。
- `npx vitest run tests/inspection.test.ts`：响应乱序、几何切换和后端错误时的属性有效性。
- `npm run test:measurement-ui`：本地后端与浏览器端到端验证拾取、多选、拖动、截面查询、材料变化及窄屏布局。
