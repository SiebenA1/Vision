# 静力分析统一工程助手

CAE 页使用右侧“工程助手”作为唯一对话入口。左侧默认显示分析参数与区域预览，手动选区、材料、载荷、网格、JSON、保存及手动求解收进“手动调整（高级）”。

## 使用

1. 在三维模型中选择实体，使用“仅分析所选实体”限定候选范围。
2. 在右侧描述分析目的。可以提供真实工况，也可以明确允许采用示例材料、载荷和安装假设。
3. 助手读取几何和区域编号，集中询问确实缺少的关键条件；条件齐全时配置工况并提交求解。
4. AI 保存的新工况自动反映到左侧。示例输入不代表真实服役工况，求解成功不等于网格精度或整体安全性获证。

例如：“检查这根柱子的横向变形；允许采用示例材料和载荷，请说明假设并完成分析。”真实工况分析则应提供实际载荷与安装条件，不能仅从外形推断。

## 数据与工具

- 复用现有 `/conversation`、`configure_study`、`solve`、`assessment`，没有另建 AI 会话或调度器。
- CAE 页发送消息时自动附带当前选择和结构化 `analysis_draft`。它允许缺少约束/载荷，按候选数据校验并限长；不能直接作为求解准入数据。
- 草稿保存在来源记录，与用户文字分开。对话显示用户原话，不显示整段 JSON；模型上下文明确标注候选值不等于已确认的材料、载荷和安装事实。
- `analysis_context` 只读提供选定实体的尺寸、真实面 ID、面积、包围盒、已有工况、相同固定/加载面提示，以及接触、共边节点和 P1 精度限制。面列表可分页。
- 当前轮次、当前版本已读取的工况上下文持续保留在 `analysis_setup`，避免截断回执后反复查询。完整页面读取后不再提供同版本 `analysis_context`；未读完允许继续分页。同一页即使变更分页大小，重复读取仍会触发停滞检测。分析任务使用独立的配置/求解流程提示，避免混入 CAD 建模步骤。
- 版本变化后旧分析上下文失效。`configure_study` 仍通过既有版本检查和任务执行边界保存；实际求解仍使用原有原生进程及数值检查。
- 相同工况配置是无修改操作；AI 再次请求相同输入时复用经当前运行环境核验的结果，不增加原生作业。同轮当前版本已有成功求解时，不再提供重复 `solve`；改变真实工况或网格后才重新提供。
- 模型接收简短数值回执，不接收绘图节点样本；最近一次求解摘要持续保留，并标记是否属于当前版本。这样后续评估不会丢失数值结果，也无需为了读取结果再次求解。
- 助手保存工况后，只有当用户未继续改动已提交草稿时才自动同步编辑器；并行手动修改保留为草稿。
- 已保存工况自动显示全部启用的固定与力标记。显式原生面读取轮廓；坐标端面仅在分析体上确有对应原生端面时预览；其余空间选区继续只显示包络。求解成功后以实际 FEM 命中节点更新显示。用户另选对象会隐藏这些标记，视口“工况标记”可重新显示。

## 验证边界

模型任务集成测试使用离线响应，验证读取上下文、保存工况和提交求解；浏览器测试拦截模型请求以检查结构化数据传递，并单独执行真实 CAD/FEA。它们不证明真实 LLM 对任意工程目标都会选择正确的物理假设；真实材料、载荷和安装条件仍需明确。
