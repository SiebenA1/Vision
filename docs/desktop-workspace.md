# 桌面工作区重设计

2026-10-24。唯一入口仍为 `http://127.0.0.1:4173/`。本批参照 Codex 桌面端的信息组织与中性色界面：左侧工程导航、中间模型工作区、右侧持续对话，设置采用侧边分类导航。

## 工作区

- 左侧直接切换已有工程；“新建工程”聚焦名称，“搜索工程”或 Ctrl/Cmd+K 聚焦工程搜索。工程管理继续支持创建、打开、重命名、工程包导出及二次确认后的永久删除。
- 中央视口占据主要空间，保留旋转、平移、缩放、坐标网格、毫米比例尺、标准视角、真实原生对象查询和命中反馈。浅色/深色主题也作用于三维场景；切换主题不重建几何或重置工程。
- 底部“数值证据 / 作业 / 版本”按需展开；方向键、Home/End 可以切换面板。显示真实校核、历史数值证据、作业日志与取消、版本恢复及版本比较。
- “工程与高级工具”打开可关闭的工程工具抽屉，保留脚本、预检、草稿恢复、原生多选、语义绑定、工况、要求和持久任务。Escape 或点击遮罩关闭，不丢弃草稿。
- 右侧助手复用真实持续对话接口。可收起，未发送草稿不会因为收起丢失；刷新也可恢复同工程草稿。执行细节收起在消息流内，执行中保留停止及调整后发送。
- 视口选择后，点击“引用到右侧对话”，或在右侧点击“引用所选对象”，把带制品身份的原生引用附到下一条消息。尚未发送的选择不自动上传，已有 epoch/head fencing 与几何失效检查继续生效。

## 设置

“设置”采用单一分类窗口，不再为每类设置堆叠模态窗口：

| 分类 | 实际功能 |
| --- | --- |
| 外观与布局 | 跟随系统/浅色/深色、对话宽度、导航折叠；保存到工作区 SQLite |
| 模型配置 | 从后端读取真实模型选项、密钥配置状态；保存到现有模型配置文件，对下一条消息或新任务生效 |
| 工程记忆 | 当前工程的来源、长期需求、决策、阶段摘要、纠正/遗忘和实际上下文检查 |
| 连接与数据 | 实际控制器状态、DeepSeek 密钥配置状态、数据库工程/版本/作业计数、数据目录、求解范围及本地模型权重状态 |

新增 `GET/POST /api/v2/ui-settings`，通过既有命令幂等机制保存 `theme`、`sidebar_collapsed`、`chat_width`。偏好位于 `workspace_settings`，独立于工程版本和工程包，不会因修改外观产生工程版本。新增 `GET /api/v2/workspace-info` 返回本地数据库统计及数据位置，不返回密钥。

连接状态不等同于一次成功的模型调用：界面只把已有后端密钥报告为“已配置”；实际请求仍由后台智能体执行、计量和保存回执。本批不恢复累计请求或 token 预算限制。

## 验证与边界

后端新增设置默认值、幂等、冲突、非法字段及重开后持久化测试。浏览器直接验证外观保存并刷新恢复、模型配置保存、连接统计、工程搜索快捷键、作业和版本面板、原生面拾取与引用、对话收起及草稿恢复、导航折叠持久化，以及窄窗口操作。

最终验证：后端85项（启用真实CAD/CAE用例）、前端56项及生产构建通过。1280px默认桌面、640px与390px断点检查无页面水平溢出；测试后恢复默认窗口、跟随系统主题、380px对话宽度和展开导航。只读核对既有模型；没有发送测试对话到该工程、修改几何或执行删除。截图位于 `screenshots/desktop-workspace-dark.png` 与 `screenshots/desktop-settings-light.png`。

保留同一后端、LLM、SQLite、不可变工程与数值证据链。本次重设计仍是浏览器工作台，不新增原生桌面安装包、云端同步、装配求解或其他物理模型；界面显示的单位仍固定为当前工程协议的 mm、N、MPa、kg。

## CAE 与解析页接入（2026-10-24）

顶部同级入口为「建模 / CAE 仿真 / 解析校核」，共用左侧工程导航、右侧持续对话、主题与设置，入口仍只有 `/`。

- CAE 页在三维视口旁显示材料、固定约束、总合力与网格编辑器，复用同一份工况草稿、旧版本校验、SQLite 工程版本和实际求解接口。高级 JSON 收起；示例草稿必须手动创建、核对和保存。草稿未保存时禁止从此页提交求解。
- 求解提交后打开作业面板；位移/应力云图、变形倍率和数值证据沿用现有结果场与版本有效性判定。工程高级工具中的工况入口统一跳转 CAE 页。
- 解析页提供矩形直杆轴向拉伸及 Euler–Bernoulli 悬臂梁公式，显式展示单位、公式与适用性提示。表单示例独立于工程，修改输入后旧参考结果清除。
- 求解器验证分标准与扩展套件，调用生产求解函数。持久任务与工程作业共用同一个控制器、进程树、内存边界、串行队列与停止机制；关闭页面不停止计算，服务中断后标记为中断而非成功。不存在新的外部服务或累计 LLM 预算。
- `verification_runs` 保存输入环境快照、阶段、错误与结果。报告携带实际依赖版本、源码 SHA256、归档网格 SHA256；实现变化后界面标记过期，LLM 不再把旧报告当作当前环境证据。校核记录独立于工程，不写入工程 head。
- 智能体增加只读 `beam_reference` 与 `solver_validation` 工具：前者要求完整参数，后者读取当前实现的最新校核。两者都明确不构成当前零件求解或设计达标证据。

接口：`POST /api/v2/calculations/beam`、`GET/POST /api/v2/solver-checks`、`GET /api/v2/solver-checks/{id}`、`POST /api/v2/solver-checks/{id}/cancel`。详细数值结果见 [CAE 校核](cae-validation.md)。

本批最终验证：后端90项（启用原生 CAD/FEA）、前端56项与生产构建通过。实际浏览器完成独立100×20×10 mm梁工程的表单编辑、保存工况、静力求解、位移/应力云图和证据查看；ν=0拉伸得到最大位移0.000238095 mm、应力0.5 MPa。临时工程随后清理，原支架工程 head `b9f0670c4bd749edaccaa7a1a3989eaa` 和未配置工况状态保持不变。扩展校核从界面提交，七个算例及同网格对照完成，报告下载后内容核对一致。640px与390px页面无整体横向溢出，表格可局部滚动；测试后恢复默认窗口和对话侧栏。截图：`screenshots/cae-workspace-verified.png`、`screenshots/solver-verification-workspace.png`。
