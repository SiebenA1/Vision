# 模型视口交互

2026-10-24。

## 查看与坐标

顶部“显示内容”切换三维模型、位移云图、应力云图。没有当前数值证据时云图不可选。“选择对象”提供面、边、实体和仅查看；默认选择面，拖动仍可旋转。滚轮缩放、右键拖动平移。

视口内提供“适应模型”、等轴测/正视XZ/俯视XY/右视YZ，以及坐标网格开关。网格位于世界 XY 平面 Z=0；世界原点处放置 XYZ 轴。左下角方向指示器根据相机姿态旋转，X红、Y绿、Z蓝，不把模型中心冒充世界原点。

右下角是按相机到观察中心的距离、视场角和视口高度计算的毫米比例尺，采用1/2/5刻度，随旋转/缩放/窗口尺寸更新。透视图中它只代表观察中心深度的比例，不是任意模型边长的测量结果。准确尺寸仍需原生几何查询。

## 点击与命中反馈

- 点中显示网格后立即显示黄色点击标记和“正在识别几何对象”。显示网格命中点以XYZ毫米列出，明确标注其为显示网格坐标。
- 后端原生几何唯一命中后显示对象名称、原始ID、轮廓高亮，以及面面积或边长。面/边/实体的真实身份继续由原生内核判断，不能用STL三角形编号代替。
- 点空白显示未命中并清除旧选择。命中模型但未识别到所选类型（例如在面内部选边）时明确提示，没有旧选择残留。
- 多个原生候选时在视口内展示候选按钮，最多16项，要求用户明确选择；不静默采用距离最小的对象。
- 查询失败在视口内提示，并保留可重新连接的错误信息。仅查看模式中点击会说明当前不能选择。
- 清除选择或按Esc清除高亮、点击标记和当前对象；切换显示内容/选择类型也会清除旧选择。旋转拖动不会误触发选择。

“对象列表 / 多选”直接打开工程对象面板。列表选择的多个对象会同步高亮、显示各自指标，并在对话输入附近显示“引用所选对象”。引用标签使用“实体1 · 面3”等易读名称，原始ID保留在提示及请求中。选择和查看不自动发送模型请求，引用后仍需用户发送消息。
