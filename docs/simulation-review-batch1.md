# 静力分析第一批界面优化

实现日期：2026-10-26。

## 行为

- CAE 工况区增加已保存工况核对，列出分析体、材料、网格设置、逐项约束及归一化后的载荷分量。未保存草稿不冒充当前求解输入。
- 逐项预览载荷箭头、固定符号和区域。原生面使用现有检查通道取得轮廓；盒、球及极值选区为求解前示意。极值示意优先使用分析体范围。
- 新求解记录各边界的稳定 ID、节点数、边界面数、面积、节点中心及最多 192 个实际节点标记。抽样标记不代替完整网格，也不改变边界选择或载荷分布。
- 全模型位移和节点平均应力极值可定位；新结果保存极值节点位移，使标记随显示倍率移动。历史结果缺失该向量时，非零倍率下提示恢复原形再定位。
- 方程求解、当前零件网格精度与设计指标分别显示。第一批没有增加网格收敛计算，因此精度检查明确为未检查。
- 图例明确只包含 FEM 边界节点范围，数值卡片明确覆盖全模型节点；两者可能不同。增加质量、安全系数及网格、算法和耗时详情。
- 工况变化后仍由原有证据核验控制云图及定位资格；失效原生绑定不予预览。
