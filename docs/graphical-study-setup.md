# 图形化静力工况设置

当前默认入口为右侧工程助手，左侧展示参数摘要。下述手工设置位于“手动调整（高级）”，作为可选编辑方式。AI 工作流见 [统一工程助手](ai-static-analysis.md)。

在 CAE 仿真页可先用“选择实体”选中零件，点击浮层“仅分析所选实体”或左侧“将所选实体用于分析”。这会创建或更新同一份工况草稿，不要求先保存约束或载荷。左侧“分析哪些实体？”始终显示范围，并区分草稿与当前已保存状态；“使用全部闭合实体”也只更新草稿。

也可点击“开始图形化设置”后配置工况。新草稿不预设约束或载荷；材料为钢材参考参数，需展开材料参数并按实际材料核对。

## 操作

1. 点击“在模型上添加固定位置”，在三维视口点击安装面，再点击“固定这些面”或“使用所选面”。固定表示该区域三个平移方向不能移动。
2. 点击“在模型上添加施力”，选择受力面，再点击“在这些面施力”。填写总力大小并选择世界坐标轴方向；“反向”翻转箭头。
3. 多面区域可通过“对象列表与多选”选择。总力在整组受力面上按面积分配，不是每个面分别施加相同大小的力。
4. 左侧卡片可重新选面、修改大小、方向或移除。显示力箭头后，修改大小与方向会更新草稿示意；箭长不表示力大小。
5. 点击“保存工况”，再运行静力分析。选面和方向调整只修改草稿，不会隐式保存或提交求解。

也可先在三维视口选面，再使用浮层中的“固定所选面”“在所选面施力”。这两个动作新增条目；更换现有条目的区域应使用卡片中的“重新选面”。

## 简化界面

- 材料参数折叠显示，展开后有各参数含义。
- 名称、启用开关、坐标极值选区及命名区域放在高级选区中。
- 网格参数折叠显示，保留体积控制和精度检查说明。
- 已保存工况核对默认折叠；它与草稿编辑明确分开。
- 固定标记为蓝色，力箭头为红色。箭头作为示意覆盖实体显示，避免受力方向向内时被遮住；不代表模型内部存在额外载荷。

选区仍通过原生 CAD 面查询确认，不以显示三角形代替真实面身份。实体、边、失效几何或分析范围外的面不会绑定为工况区域。几何变化后需重新绑定。

选择新对象或清除选择时，旧的边界示意会隐藏。选中整个支撑柱只是几何选择，不会自动把已有载荷改到支撑柱上；应在对应施力卡片中重新选择具体表面。坐标极值、盒、球选区在求解前只显示范围包络，不在其虚拟中心画力箭头。确认原生面或取得实际 FEM 节点后，箭头附着于该区域的边界采样点，避免平均中心落入空洞或其他实体之间。

本次支持沿世界坐标轴和自定义向量设置方向；尚未提供拖拽箭头旋转、按面法向施力或压力载荷。
